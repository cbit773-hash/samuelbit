## 9. INTEGRACIÓN CON EL CRM (InvestPRO)

### Flujo Automático: Google Ads → CRM → Agente

```
1. Usuario hace clic en anuncio de Google
2. Llega a Landing Page con UTM tags
3. Llena formulario (Nombre, Email, Tel, País)
4. Webhook envía datos a Supabase (tabla: leads)
   → status: 'Nuevo'
   → interest: detectado por campaña (utm_campaign)
   → country: auto-detectado
5. CRM asigna automáticamente al agente con menos cola
6. Agente recibe notificación y llama en <5 minutos
7. Si no contesta → status: 'No contesta' → Callback 2h
8. Si cierra → status: 'Cerrado (FTD)' → Registro de depósito
```

### UTM Tags para Tracking
```
?utm_source=google
&utm_medium=cpc
&utm_campaign=crypto_search_co
&utm_content=anuncio_bitcoin_250
&utm_term={keyword}
```
